# Figma Prompt: VelaRi Programming Language Brand System

## Project brief

Design a complete, professional visual identity for **VelaRi**, an early-stage Rust-based programming language and compiler project for safe, fast, cross-platform native desktop applications.

VelaRi should feel technically serious, modern, precise, approachable, and durable. The identity must communicate language design, native compilation, developer tooling, safety, performance, and cross-platform capability. It must not look like a generic software startup, cryptocurrency project, gaming brand, or children’s coding product.

The visual system should remain useful as VelaRi grows from a compiler and interpreter into a complete native application platform.

## Brand attributes

Use these attributes as design constraints:

- **Precise:** clean geometry, intentional spacing, controlled proportions
- **Native:** confident and grounded rather than cloud-only or abstract
- **Safe:** stable, trustworthy, and technically responsible
- **Fast:** visual momentum without aggressive racing imagery
- **Cross-platform:** adaptable forms and balanced visual structure
- **Developer-first:** readable, functional, and comfortable in documentation and tools
- **Open-source capable:** welcoming and transparent without appearing casual or unfinished

## Primary deliverables

Create a Figma file with organized pages and reusable components for:

1. **Primary logo mark**
   - A distinctive symbol that can stand alone at small sizes.
   - The mark should work in one color before color is added.
   - Avoid literal computer chips, terminal windows, brackets, generic atoms, and stock rocket imagery.
   - Explore concepts related to structured language, safe transformation, native foundations, pathways, layers, or a precise abstract glyph.

2. **Wordmark**
   - The exact spelling is `VelaRi` with a capital `V` and capital `R`.
   - Produce a horizontal wordmark and a compact lockup.
   - The typography should be highly legible in README headings, release pages, terminal-adjacent interfaces, and editor tooling.

3. **Logo lockups**
   - Mark only
   - Wordmark only
   - Mark plus wordmark horizontal
   - Mark plus wordmark stacked
   - Small-size favicon/icon lockup

4. **GitHub repository banner**
   - Wide composition suitable for a GitHub social preview.
   - Preserve a quiet, readable center area for cropping safety.
   - Include the VelaRi wordmark and a restrained technical motif.
   - Do not place critical text near the far edges.

5. **Language and application icon**
   - Square icon for file associations, editor extensions, documentation, and future desktop applications.
   - Export guidance for 16px, 32px, 48px, 128px, and 256px sizes.
   - Ensure the mark remains recognizable at 16px.

6. **Documentation and syntax icon**
   - A simple monochrome icon that can appear beside language documentation, code examples, and navigation items.

## Visual exploration

Create 3–5 distinct initial logo directions before selecting one. Each direction should include:

- A short concept name
- The visual idea in one sentence
- A black-and-white mark
- A color mark
- A small-size test
- A horizontal lockup
- A note explaining why it fits VelaRi

Favor abstract, ownable geometry over obvious literal symbols. The final mark should be recognizable without the word `VelaRi`.

## Color system

Propose a restrained, accessible palette with named tokens:

- Primary brand color
- Secondary brand color
- Dark background
- Light background
- Primary text
- Muted text
- Success or valid-state color
- Diagnostic or error color
- Optional accent color

Provide HEX, RGB, and HSL values. Check contrast for normal text and interface labels. The logo must also work in pure black, pure white, and grayscale.

Do not assume that a neon gradient is required. If gradients are used, define a flat-color fallback and keep the gradient subtle enough for technical documentation.

## Typography

Recommend a primary display or wordmark typeface and a supporting UI/documentation typeface. Prefer fonts with clear licensing or commonly available open-source alternatives.

Define:

- Wordmark treatment
- Heading style
- Body text style
- Code sample style
- Letter spacing
- Recommended weights
- Fallback fonts

The branding should pair comfortably with Rust documentation, GitHub Markdown, terminal output, and code editors.

Include a concise brand usage page showing:

- Minimum logo size
- Required clear space
- Approved backgrounds
- Approved monochrome versions
- Incorrect stretching
- Incorrect rotation
- Incorrect recoloring
- Incorrect placement over busy imagery
- Incorrect use of the mark as a generic decorative shape

## Tone to avoid

Do not make VelaRi look:

- Childish or cartoon-like
- Corporate and generic
- Like a cryptocurrency token
- Like a cybersecurity alarm product
- Like a gaming engine
- Like a cloud hosting service
- Like a direct clone of Rust, Go, Zig, Swift, or Kotlin branding
- Dependent on a complicated gradient or detailed illustration

## Final presentation

End the Figma file with a concise brand board showing:

- Final wordmark
- Color palette

- Light and dark usage

- Language icon

The result should be polished enough to serve as the source of truth for the VelaRi GitHub repository, future documentation site, editor extension, release assets, and native application tooling.
